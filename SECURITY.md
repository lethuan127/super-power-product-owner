# Security

## Report a problem

Do not open a public issue for a security problem. Use GitHub's private report instead:
**Security** tab → **Report a vulnerability**.

Examples of a security problem here:

- a skill sends, saves or publishes data without the user's "yes";
- a skill follows an instruction hidden in a file, a web page or a message;
- a skill writes a password, a token or personal data to a file or an issue.

The maintainer answers within 7 days. This is a one-person, best-effort project.

## Supported versions

Only the latest version gets fixes.
