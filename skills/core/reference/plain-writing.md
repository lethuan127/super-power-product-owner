# Plain writing

Write for a busy reader who may read the project language as a second language.

1. Use the language in `CLAUDE.md`, unless the user asks for another one. Keep product terms as
   the team says them, even in English inside a Vietnamese text.
2. Use the users' words from `users.md` and `terms.md`. Write "order", not "record", if the
   users say "order".
3. One idea per sentence. Aim for 10 to 15 words.
4. Say who does what: "Accounting sends the file", not "the file is sent".
5. Put the answer or the action first.
6. Explain a term the first time you use it, in the next sentence.
7. Keep every number, date and name exact. Write "?" for a fact you do not have.
8. Use a numbered list for steps, and a table to compare.
9. No filler words, and no idioms.
