# Artifacts

An artifact is a web page that Claude publishes, with a private link. It can have filters,
sliders and comments.

## When to offer one

Offer an artifact when other people will read the result, such as a manager or accounting.
Ask once: "Do you want this as a page you can share?" If the user says "no" twice, add
"Artifacts: no" to `CLAUDE.md`, and stop asking.

## Rules

1. **Private first.** The user shares the link. Never share it yourself.
2. **No customer data on a page the user will share,** unless the user says yes for that page.
   See `redact.md`.
3. **The wiki stays the record.** Link the page back to the wiki pages and the sources.
4. **One link for a repeated report.** Update the same artifact each week. Save its link in
   `CLAUDE.md`.
5. **Always a file too.** A reader may need a Claude account to open the page. So save the same
   result as a file the user can send, such as `.xlsx`, `.docx` or `.md`.

If you cannot publish an artifact here, save the file only, and tell the user.
