# Redact

## What to remove

Remove these from **quotes** and from **wiki pages**:

- a person's name: write the role, such as "the accounting lead" or "a sales staff member";
- a phone number: write `[phone]`;
- a mail address: write `[mail]`;
- a customer's name: write `Customer A`, `Customer B`, and keep the same letter for the same
  customer in one document;
- an ID number, a bank account or a card number: write `[id]`.

## What to keep

- A task owner in the output of a meeting or status skill. A task needs a person. That output
  goes to the team, not into the wiki.
- Names the user writes into a document on purpose, such as a sign-off line.
