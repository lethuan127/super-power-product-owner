# Vietnamese output

Read this file when the project language is Vietnamese. It sets fixed phrases and formats, so
every guide and report reads the same. The rules in `plain-writing.md` still apply.

## Words to keep as they are

- Button, field, column and screen names: exactly as the product shows them, in bold.
- Common team words: user story, backlog, sprint, release, UAT, ticket, spec, bug.
- File names and paths.

## Fixed headings and phrases

| English template | Vietnamese |
|---|---|
| For | Dành cho |
| After this guide you can | Sau hướng dẫn này, bạn có thể |
| Before you start | Trước khi bắt đầu |
| Steps | Các bước |
| Result | Kết quả |
| Note | Lưu ý |
| Common mistakes | Lỗi thường gặp |
| You see / Why / What to do | Bạn thấy / Lý do / Cách xử lý |
| Help | Cần hỗ trợ |
| Ask <role> in <place> | Hỏi <vai trò> tại <nơi> |
| Matched | Khớp |
| Only in A / Only in B | Chỉ có ở A / Chỉ có ở B |
| Amount differs | Lệch số tiền |
| Keys / Sum A / Sum B | Số mã / Tổng A / Tổng B |
| Lines with no key | Dòng không có mã |
| Lines with a bad amount | Dòng có số tiền lỗi |
| Special cases | Trường hợp đặc biệt |
| Biggest gaps | Chênh lệch lớn nhất |
| difference | chênh lệch |
| Cause: ? | Nguyên nhân: ? |
| All lines counted, totals agree | Đã tính đủ mọi dòng, tổng khớp |
| Result file | File kết quả |
| screenshot | ảnh màn hình |

Write `[ảnh màn hình: <tên màn hình>]` where a screenshot belongs.

## Formats

- Numbers: dot for thousands, comma for decimals: `1.234.567,5`. Copy the digits from the
  source exactly. Change only the marks.
- Money: `1.234.567 ₫`, or the currency in `money.md`.
- Dates: `13/11/2026`. File names keep `YYYY-MM-DD`.

## Tone

- Call the reader "bạn". Never "quý khách" or "anh/chị" in a guide.
- Short, direct sentences: "Bấm **Lưu**." not "Bạn hãy vui lòng bấm vào nút **Lưu**."
- Use "bấm" for a click, "nhập" for typing in a field, "chọn" for a list.
